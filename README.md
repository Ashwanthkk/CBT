> **Note:** The entire backend codebase was designed and written by me from scratch.
>
> **Contribution Guidelines:**
> - **Backend:** LLM-generated code is not allowed. Contributors must write and understand the backend code themselves. AI may be used for learning, understanding concepts, troubleshooting errors, debugging, or getting guidance, but not for generating backend implementations or system designs blindly.
> - **Frontend:** LLM-generated code is allowed.
> - **Testcode:** LLM-generated test scripts  are allowed.
> Contributions are welcome, as long as these guidelines are followed.
