> **Note:** The entire backend codebase was designed and implemented by me from scratch.
>
> **Contribution Guidelines:**
> - **Backend:** LLM-generated code is not permitted. Contributors are expected to write and understand the backend implementation themselves. AI may be used for learning, understanding concepts, troubleshooting, debugging, and guidance, but not to generate backend code or design the system blindly.
> - **Frontend:** LLM-generated code is permitted.
> - **Testing:** LLM-generated test scripts are permitted.
>
> Contributions are welcome, provided these guidelines are followed.
